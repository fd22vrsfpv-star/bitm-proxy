Reconnaissance & capture demos

Silent fingerprinting — visit this link and it captures your browser's device fingerprint with no form, no visible interaction, then funnels you into the lab login session — which replays the exact device it just fingerprinted, so the IdP sees your real browser, not the server's. The same drive-by recon-to-session technique covered in the talk, running against your own browser.

Credential lander page — a login-page template that demonstrates how a phishing lander captures input and redirects to the real login portal afterward, so the flow looks unbroken.

Do not enter real credentials on the lander page. It submits whatever you type to this lab's capture store and then sends your browser on to the real Microsoft login portal. Type anything — the point is to see the mechanism, not to actually sign in.

Run this yourself

Want to try this against your own tenant instead of the lab one? This entire lab is the same open-source Docker image — clone the repo and run it under your own authorization:

git clone https://github.com/fd22vrsfpv-star/bitm-proxy.git
cd bitm-proxy
./run_demo.sh   # macOS / Linux — or .\run_demo.ps1 on Windows

Defaults to https://127.0.0.1/, reachable only from your own machine. Works on Linux, macOS (including Apple Silicon), and Windows (Docker Desktop, WSL2 backend recommended) — see the repo's docs/DEFCON-LAB-SETUP.md for details, including the self-signed-certificate step for local use.
